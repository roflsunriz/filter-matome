# 動画変換ツール (convert-any-to-h264.pyw)

## 概要
このツールは、様々な形式の動画ファイルをH.264、HEVC (H.265)、AV1形式に変換できる便利なGUIアプリケーションです！

## 主な機能
- ドラッグ＆ドロップでの簡単なファイル追加
- 複数ファイルの一括変換
- HLSフォルダの変換対応
- 4つの変換モード
  - **AVC (H.264)**: 互換性重視
  - **HEVC (H.265)**: 圧縮効率重視
  - **AV1**: 最新の圧縮技術
  - **アダプティブコピー**: H.264映像はコピーし、音声のみAACに変換
- リアルタイムの変換進捗表示
- 詳細なログ表示

## 必要環境
- Python 3.x
- FFmpeg（システムパスに設定されていること）
- 必要なPythonパッケージ: `tkinterdnd2`

## 使い方
1. `convert-any-to-h264.pyw` を実行してプログラムを起動します。
   - `.pyw` ファイルをダブルクリックするか、コマンドプロンプトで `pythonw convert-any-to-h264.pyw` を実行します。
2. 以下のいずれかの方法で変換したいファイルやフォルダを追加します。
   - 「動画ファイルを追加」ボタンでファイルを選択
   - 「HLSフォルダを追加」ボタンでフォルダを選択
   - ウィンドウにファイルやフォルダを直接ドラッグ＆ドロップ
3. 変換したいコーデックを選択します。
4. 「変換開始」ボタンをクリックすると、変換が始まります。

## 注意事項
- 初回起動時に `tkinterdnd2` がインストールされていない場合、自動インストールの確認ダイアログが表示されます。
- FFmpegがインストールされていない、またはPATHが通っていない場合は動作しません。
- 変換されたファイルは、スクリプトを実行したディレクトリに `convert_元のファイル名.mp4` という名前で保存されます。

## エラー対応
もしエラーが発生したら、ログ表示欄を確認してください。主な対処方法は：
1. **FFmpegが正しくインストールされているか確認**: コマンドプロンプトで `ffmpeg -version` を実行して確認できます。
2. **入力ファイルが破損していないか確認**: 他のプレイヤーで再生できるか試してください。
3. **十分なディスク容量があるか確認**: 変換には一時的に多くのディスク容量が必要になる場合があります。
