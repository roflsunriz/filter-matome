# 10s-cut.bat

## 概要

`10s-cut.bat` は、指定した動画・音声ファイルの先頭10秒をffmpegで切り出す簡易バッチです。複数ファイルをまとめて指定できます。

## 必要環境

- Windows
- `ffmpeg` コマンドがPATHから実行できること

## 使い方

ファイルを `10s-cut.bat` へドラッグ＆ドロップするか、コマンドラインから入力ファイルを渡します。

```bat
scripts\10s-cut.bat input.mp4
scripts\10s-cut.bat input1.mp4 input2.mp4
```

出力は `scripts` フォルダへ `10s_<元のファイル名>` という名前で作成されます。

## 注意事項

- 同名の出力ファイルが存在する場合、ffmpegが上書き確認を表示します。
- 引数を引用符で保護していない簡易バッチのため、空白や特殊文字を含むパスでは正しく動作しない場合があります。
- コーデックを明示していないため、出力形式によってはffmpegの既定設定で再エンコードされるか、変換に失敗する場合があります。
- 処理終了後は確認のためキー入力待ちになります。
