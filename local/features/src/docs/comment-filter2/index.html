各項目の設定方法

ルール形式について

CommentFilter2はJSON Lines形式でルールを管理・実行します。

  • JSON Lines形式: 実際のフィルタリングに使用される形式
  • CSV形式: 従来形式からの移行（マイグレーション）専用

重要：CSV形式のルールは自動的にJSON Lines形式に変換されてから実行されます。

JSON Lines形式（メイン形式）

CommentFilter2で実際に使用される形式です。1行に1つのJSONオブジェクトを記述します。

基本構造

{
  "pattern": "正規表現パターン",
  "flags": "gi",
  "action": {"type": "replace", "replacement": "置換後文字列"},
  "smid": ["ALL"],
  "enabled": true
}

パターンマッチングルール

正規表現ルール： 
{"pattern": "バカ|アホ", "flags": "gi", "action": {"type": "replace", "replacement": "***"}, "smid": ["ALL"]}
ユーザーIDルール： 
{"userId": "TKAF1N8IB3c8D0WJ3l8xixNrwyQ", "action": {"type": "hide"}, "smid": ["ALL"]}

アクションタイプ

  • hide: コメントを非表示にする 
    {"action": {"type": "hide"}}
  • replace: コメントを置換する（正規表現ルールのみ対応） 
    {"action": {"type": "replace", "replacement": "置換後文字列"}}
  • unspecified: 未指定（デフォルト動作、ニコる数条件との組み合わせ専用） 
    {"action": {"type": "unspecified"}}

重要な制限事項

  • ユーザーIDルールは「hide（非表示）」と「unspecified（除外のみ）」のみ対応しています
  • replace（置換）は正規表現ルールでのみ利用可能です
  • unspecified（除外のみ）はニコる数条件と同時に設定することを前提としており、単独では意味がありません

SMID指定

  • 全動画対象："smid": ["ALL"]
  • 特定動画のみ："smid": ["sm1234567890"]
  • 複数動画："smid": ["sm1234567890", "sm0987654321"]

ニコる条件（オプション）

指定数以上で除外： 
"nicoru_cond": {"op": ">=", "value": 5, "mode": "exclude"}
範囲指定： 
"nicoru_cond": {"op": "range", "value": [3, 10], "mode": "include"}
  • 演算子：=, >, <, >=, <=, range
  • モード：include（条件に合致するもののみ）, exclude（条件に合致するものを除外）

その他のオプション

  • enabled: ルールの有効/無効（デフォルト: true）
  • description: ルールの説明文
  • id: ルールの一意識別子
  • flags: 正規表現フラグ（デフォルト: "gi"）

完全な例

// コメント行（// または # で開始）
{"pattern": "荒らし|スパム", "flags": "gi", "action": {"type": "hide"}, "smid": ["ALL"], "description": "荒らしコメント除去"}
{"userId": "TKAF1N8IB3c8D0WJ3l8xixNrwyQ", "action": {"type": "hide"}, "smid": ["sm1234567890"], "nicoru_cond": {"op": "<", "value": 3, "mode": "include"}}
{"pattern": "草+", "flags": "g", "action": {"type": "replace", "replacement": "w"}, "smid": ["ALL"], "enabled": false}

CSV形式（マイグレーション専用）

注意：CSV形式は従来形式からの移行専用です。実際のフィルタリングはJSON Lines形式で実行されます。

/正規表現/,/置換後表現/,SMID,ニコる数 の順番で入力します。

例：/置換したいコメント/,/置換された後のコメント/,sm1234567890,3
  • 置換後表現：置換したいものがないときは /EMPTY/ を指定
  • SMID：特定の動画でのみ動作させる場合に指定。全動画対象の場合は ALL
  • ニコる数：指定した数以上のニコる数を持つコメントをフィルターから除外。指定なしの場合は EMPTY
全動画対象の例：/正規表現/,/EMPTY/,ALL,EMPTY
→ 正規表現にマッチするコメントを非表示、全動画対象、全ニコる数対象

複雑な正規表現の入力方法（NEW!）

量指定子（{1,10}など）を含む正規表現は、ダブルクォートで囲んで入力してください：

  • "/(([^\\]{1,10}?))(?:\\2){3,}(?=[^\\]*)/",/草/,ALL,EMPTY
  • "/test{1,5}pattern/",/置換/,sm1234567890,EMPTY

ダブルクォート自体を含む場合は二重化してください：

  • "正規表現内で""クォート""を使用",置換後,ALL,EMPTY

これにより「unterminated parenthetical」エラーが解消されます。

正規表現フラグ（オプション）の指定方法

正規表現には以下のフラグを指定できます（完全なES6+対応）：

  • g: グローバル検索（複数回マッチ）
  • i: 大文字小文字を区別しない
  • m: 複数行モード（^と$が行の始まり・終わりにマッチ）
  • u: Unicode モード（正しいUnicode処理）
  • y: sticky モード（前回マッチした位置から継続検索）
  • s: dotAll モード（.が改行文字にもマッチ）
  • d: hasIndices モード（マッチした位置情報を取得）

フラグの使用例：

  • /test/gi,/置換/,ALL,EMPTY （大文字小文字無視 + グローバル）
  • "/pattern{1,3}/imu",/結果/,sm123,EMPTY （複数フラグ + クォート囲み）
  • /\\\\s+/gms,/EMPTY/,ALL,EMPTY （空白行除去 + 複数行 + dotAll）
  • /😀+/gu,/笑/,ALL,EMPTY （絵文字 + Unicode + グローバル）
フラグの組み合わせのコツ：
  • gi: 最も一般的（大文字小文字無視 + 全体検索）
  • gim: 複数行テキストに対応
  • giu: 日本語や絵文字を含む場合におすすめ
  • gims: 改行を含む複雑なパターンマッチング

※ フラグを省略した場合は自動的に「gi」が適用されます。重複フラグや無効フラグは自動的に正規化されます。

CSV形式 - NGユーザールール

@ユーザーID,SMID,ニコる数 の順番で入力します。

例：@ユーザーID,sm1234567890,3
→ 指定ユーザーのコメントを非表示、特定動画のみ、ニコる数3以上は除外
  • SMID：特定の動画でのみ動作させる場合に指定。全動画対象の場合は ALL
  • ニコる数：指定した数以上のニコる数を持つコメントをフィルターから除外。指定なしの場合は EMPTY
全動画対象の例：@ユーザーID,ALL,EMPTY
→ 指定ユーザーのコメントを非表示、全動画対象、全ニコる数対象

ユーザーIDルールの制限

ユーザーIDルール（CSV形式の@ユーザーID、JSON形式のuserIdルール）は非表示（hide）のみ対応しています。置換（replace）機能は利用できません。

CSV形式からの移行

既存のCSV形式ルールは自動的にJSON Lines形式に変換されます。インポート時に自動判定・変換が行われます。

CSV: /バカ/,/アホ/,ALL,5
JSON Lines: {"pattern": "バカ", "flags": "gi", "action": {"type": "replace", "replacement": "アホ"}, "smid": ["ALL"], "nicoru_cond": {"op": ">=", "value": 5, "mode": "exclude"}}

正規表現とファイル形式について

正規表現について

正規表現可。(ユーザーIDは正規表現不可。)正規表現の特殊キーワードを文字として扱う場合はエスケープしてください。例えば.をエスケープする場合\.としてください。

CSV形式での重要な注意：量指定子（{1,10}など）を含む正規表現は、全体をダブルクォートで囲んで入力してください。

JSON Lines形式では：正規表現は文字列として記述するため、エスケープが必要です。例："pattern": "\\d{1,3}"

ファイル形式の自動判定

CommentFilter2は以下の形式を自動判定します：

  • .jsonl: JSON Lines形式
  • .json: JSON形式（コレクション）
  • .csv: CSV形式（従来形式）

ファイル拡張子に関係なく、内容から自動判定されるため、どの拡張子でも使用可能です。

エクスポート・インポート機能

  • エクスポート: 現在のルールをJSON Lines形式でダウンロード
  • インポート: CSV、JSON Lines、JSON形式のファイルを読み込み
  • 自動変換: CSV形式は自動的にJSON Lines形式に変換されてから実行されます

重要：すべてのルールは最終的にJSON Lines形式で管理・実行されます。
