# 注意1: 導入・除去にはwatchページのハード再読み込みが必要
#       大抵のモダンブラウザでは Ctrl + F5 でディスクキャッシュを上書きしつつ再読み込みする
# 注意2: 公式プレイヤーが動かなくなる可能性あり(ソースコードを無理やり書き換えているため)
# 動画の再生・一時停止・スキップ・シーク・再生速度変更など、非プレミアム会員で制限されている

# 実質的な機能はmlink-video-controllerで提供している。

# serverContext書き換え用プレースホルダー。
# このReplaceには設定値だけを置き、書き換えとコメント投稿保護のロジックは
# TypeScript製のserver-context-override.jsへ集約する。
# enabledがfalseの項目は変更しない。変更する項目だけtrueにしてvalueを設定する。
# valueは文字列、数値、真偽値、null、配列、オブジェクトを使用できる。
# 未知のプロパティは保持し、動画種別によって対象パスが存在しない場合はその項目だけ無視する。
# sessionUser.typeを書き換えても、nvCommentの通常コメント投稿では書き換え前の会員種別を使う。
# regular・未ログインではpremiumフラグを無効化してプレミアム専用色を除き、
# 最初からpremiumの場合は投稿本文を変更しない。
# publicUrl.*は公式クライアントの接続先なので、変更時は接続先を確認すること。
# 認証状態や視聴権限などサーバー側で検証される値を変えても、権限は付与されない。
